# Simple and Fun JavaScript Exercises

A collection of beginner JavaScript exercises covering several core programming concepts.

## About

This project contains short exercises created while practicing JavaScript fundamentals.

Each section focuses on a different concept and provides a small problem to solve.

## Topics Practiced

### Variables

- Declaring variables
- Assigning values
- Reassigning values
- Working with strings
- Accessing individual string characters

### Functions

- Declaring functions
- Passing arguments
- Using parameters
- Performing calculations
- Calling functions

### Conditionals

- `if`
- `else`
- Comparing values
- Working with strings
- Logical operators

### Loops

- `for` loops
- Counters
- The remainder operator
- Skipping values based on a condition

## Technologies

- HTML5
- CSS3
- JavaScript

## Running the Project

1. Clone or download the repository.
2. Open `index.html`.
3. Follow any browser alerts.
4. Open the browser developer tools.
5. Select the Console to view logged output.

## Purpose

This repository documents early JavaScript exercises used to strengthen programming fundamentals before moving on to larger applications.

The focus is on understanding the building blocks of JavaScript rather than creating one large application.
